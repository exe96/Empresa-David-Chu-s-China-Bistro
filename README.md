Recomendación para funcionamiento si quieren clonar el proyecto:
1- edit .env
2- usar mamp y respaldar base de datos:
3- instalar composer y php en tu sistema
4- abre una terminal(en la ubicación) en la carpeta del proyecto
5- En la ubicación de la terminal usar comandos " php artisan serve "   se levantará el proyecto web en el localhost. Otro comando es
" php artisan serve --host=192.168.1.7 --port=8080 " se levanta en tu red local y podes ver el proyecto en los dispositivos que estén en tu red local.
6-Puedes abrir el proyecto en visual studio code y ir a la terminal y poner el comando mencionado anteriormente



Recommendation for running the project if you want to clone it:
1-Edit the .env file.
2-Use MAMP and back up the database.
3-Install Composer and PHP on your system.
4-Open a terminal (in the project folder's location).
In the terminal, run the command:
php artisan serve → This will start the web project on localhost.
php artisan serve --host=192.168.1.7 --port=8080 → This will start the project on your local network, allowing you to access it from any device connected to the same network.
You can also open the project in Visual Studio Code, go to the terminal, and run the mentioned command there
