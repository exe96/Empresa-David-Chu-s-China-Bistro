# Recomendación de prueba del proyecto:

## Que hace el proyecto
Es un Catálogo (Menú)  el cual se pueden agregar, eliminar y actualizar, categorías e ítems. Tienes un usuario de prueba el que te permite realizar estas acciones. Solo necesitas ir a admin en la parte inferior de la página y hacer el login

## Configuración basica
- Edit .env
- Usar mamp y respaldar base de datos:
- Instalar composer y php en tu sistema
- Abre la carpeta del proyecto con visual estudio code y ve a terminal, nueva terminal.
- En la terminal usa el comando " php artisan serve " se levantará el  proyecto web en el localhost. 
- Otro comando es " php artisan serve --host=192.168.1.7 --port=8080 " se levanta en tu red local y podes ver el proyecto en los dispositivos que estén en tu red local.

# Project Test Recommendation:

## What the project does
It is a catalog (menu) where you can add, delete, and update categories and items. There is a test user that allows you to perform these actions. You just need to go to the admin section at the bottom of the page and log in.

## Basic configuration
- Edit the .env file.

- Use MAMP and back up the database.

- Install Composer and PHP on your system.

- Open the project folder in Visual Studio Code, then open a new terminal.

- In the terminal, use the command php artisan serve to start the web project on localhost.

- Alternatively, use the command php artisan serve --host=192.168.1.7 --port=8080 to start the project on your local network, so you can access it from devices connected to the same network.
